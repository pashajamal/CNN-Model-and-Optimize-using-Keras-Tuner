# CNN Model and Optimize using Keras Tuner

A Jupyter Notebook that builds a Convolutional Neural Network (CNN) with Keras and improves it by automatically searching for the best hyperparameters using Keras Tuner.

## What's Inside

- `cnn-model-and-optimize-using-keras-tuner.ipynb` – the main notebook

## What It Does

1. Loads and preprocesses the data
2. Builds a CNN model with Keras
3. Uses Keras Tuner to search for the best hyperparameters
4. Trains and evaluates the best model

## Requirements

- Python 3
- TensorFlow / Keras
- keras-tuner
- NumPy
- Matplotlib

```bash
pip install tensorflow keras-tuner numpy matplotlib
```

## How to Run

```bash
git clone https://github.com/pashajamal/CNN-Model-and-Optimize-using-Keras-Tuner.git
cd CNN-Model-and-Optimize-using-Keras-Tuner
jupyter notebook cnn-model-and-optimize-using-keras-tuner.ipynb
```
